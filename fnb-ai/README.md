F&B AI — Frontend

Scaffolded Next.js + TypeScript starter using Tailwind and Framer Motion.

Setup

1. Install dependencies:

```bash
cd fnb-ai
npm install
```

2. Run dev server:

```bash
npm run dev
```

Notes

- This scaffold includes base layout, hero, features, and basic animations.
- Next steps: add Shadcn UI, Magic UI components, and additional pages/components.
